## 👋 About

How to WP is a monthly subscription, priced like a single plugin, that gives you a full repository of open-source, license-free WordPress plugins and themes.

- **For everyday users:** no per-plugin cost, secure, no limits.
- **For vibe coders & developers:** open, extendable code so you can build on top of it with fewer tokens.

## 📦 What's here

- 🔌 **Plugins:** How to WP WordPress plugins
- 🎨 **Themes:** WordPress themes
- 🛠️ **Scripts:** helper tools for building and releasing
