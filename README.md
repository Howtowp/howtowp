## هر ابزاری که لازم داری، همین‌جا پیداش کن

How to WP یک **اشتراک ماهانه** است — تقریباً به‌قیمت یک افزونه — که به مخزن افزونه‌ها و قالب‌های **متن‌باز و بدون قفل لایسنس** وردپرس دسترسی می‌دهد.

سورس کاملاً خواناست، ionCube یا مبهم‌سازی ندارد، و روی سایت‌های خودتان بدون فعال‌سازی اجباری یا محدودیت دامنه نصب می‌شود.

## برای چه کسانی است؟

- **صاحبان سایت و فروشگاه:** لازم نیست برای هر نیاز یک افزونه جدا بخرید. با یک اشتراک به مجموعه دسترسی دارید؛ امن، بدون هزینهٔ جداگانه برای هر محصول و بدون محدودیت غیرضروری.
- **وایب‌کودرها و توسعه‌دهنده‌ها:** کد باز و قابل‌گسترش است. می‌توانید افزونه‌ها را بخوانید، هوک اضافه کنید و سفارشی‌سازی کنید — و برای کار با دستیارهای هوش مصنوعی معمولاً توکن کمتری لازم است.

## About How to WP

How to WP is a **monthly subscription**, priced like a single plugin, that unlocks a repository of **open-source, license-free** WordPress plugins and themes.

The code is readable — no ionCube, no obfuscation — and you can install it on your own sites without a license lock or domain cap.

### Who it’s for

- **Site and store owners:** no per-plugin purchase, secure access, and no unnecessary limits. One subscription covers the collection.
- **Vibe coders and developers:** open, extensible plugins you can read, hook into, and customize — usually with fewer tokens when you work alongside an AI assistant.
